# AI-Driven Phishing Detection System

## Overview

This project is an AI-driven phishing detection system developed using Machine Learning. The main purpose of this project is to identify phishing websites and help users stay safe from cyber attacks.

The system analyzes website-related features and predicts whether a website is legitimate or phishing.

---

## Features

* Detects phishing websites
* Machine learning-based prediction
* User-friendly interface
* Fast and accurate detection

---

## Technologies Used

* Python
* Machine Learning
* Scikit-learn
* Pandas
* NumPy
* Flask
* HTML/CSS

---

## How It Works

1. Dataset is collected and preprocessed
2. Important features are extracted
3. Machine learning model is trained
4. User enters a website URL
5. System predicts whether the website is safe or phishing

---

## Project Structure

* app.py → Main Flask application
* model.pkl → Trained machine learning model
* templates/ → HTML files
* static/ → CSS and static files

---

## Installation

1. Clone the repository
2. Install required libraries using:

pip install -r requirements.txt

3. Run the Flask application:

python app.py
